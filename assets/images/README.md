# 背景图片文件夹

## 必需文件：
- `background.png` - 应用会在初始化时自动加载这个文件

## 可选文件：
- `background.jpg` - 备用背景图片
- `bg.jpg` / `bg.png` - 其他格式的背景图片

## 建议的图片规格：

- **分辨率**: 1920x1080 或更高
- **格式**: JPG 或 PNG
- **文件大小**: 建议小于 5MB
- **内容**: 适合作为3D人物背景的场景图片

## 使用方法：

1. 将背景图片文件复制到此文件夹
2. 在应用中点击"设置"区域的"背景图片"开关
3. 应用会自动尝试加载可用的背景图片
4. 如果没有找到图片文件，会使用蓝灰色纯色背景

## 注意事项：

- 图片会自动缩放以填充屏幕高度
- 背景图片会显示在3D模型后面
- 可以随时通过开关控制显示/隐藏
